# Kiez material refresh

`Kiez-refined.png` is a refined edit of `Kiez-retro.png`, matching the craft of
Mitte-retro and BerlinPrenzlberg-retro. The old image remains available; no
existing source artwork was overwritten.

The refined PNG is 1671x941, one column narrower than the original. Its
source rectangle is recorded explicitly in `berlin-gameplay.json`; it maps
to the same 1152x648 world. All original object silhouettes, footprints,
anchors, interactions and the Kiez scene file remain unchanged. Targeted
rendered front/back contacts, the stone strip and exit route were checked.
The opening uses this same image, and ordinary Kiez activity shots obtain it
through the shared environment catalog.
