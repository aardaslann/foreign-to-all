# Design material index

For the current eight-city beta, start with [player-journey.md](player-journey.md) and the [three-page PDF](foreign-to-all-player-journey.pdf). The corresponding `.drawio` file is editable; `journey-page-1.png` through `journey-page-3.png` are previews.

The other files in this folder are historical working designs and production records. They show earlier ideas, including a fragment-recovery storyline, smaller playable scope, and planned destinations. They are retained as process material and may describe mechanics that were superseded. They are not the current feature list; use the [project overview](../PROJECT.md), [player guide](../beta-player-guide.md), and actual source for that.

`trailer/` contains early storyboard and build notes. Local paths in these historical records identify the original working environment and are not setup prerequisites.
