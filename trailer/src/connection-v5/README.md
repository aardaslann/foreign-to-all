## Build

Run from the trailer folder with Python containing numpy, scipy, soundfile and edge-tts; importing the existing instrument module does not invoke speech generation. FFmpeg must be on PATH.

```powershell
python src/connection-v5/build_intro.py
node node_modules/typescript/bin/tsc --noEmit
node node_modules/@remotion/cli/remotion-cli.js render src/connection-v5/index.tsx ConnectionV5 out/foreign-to-all-understanding-v5.mp4 --codec=h264 --pixel-format=yuv420p --crf=17 --image-format=png --audio-bitrate=256k --concurrency=8
```

`intro.ts` is generated by the audio builder. `Connection.tsx` maps playback time onto revision 4's story clock so existing text, gestures and dialogue remain synchronized. `public/connection-v5` contains the new mix and separate stems. Mastering retains the previous fixed gain to preserve the established dialogue and score levels.
